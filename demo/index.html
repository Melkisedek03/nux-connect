NUX Connect — Provider Smoke Test

Minimal test page for the provider: it detects the injected window.nux provider, asks to connect (nux_requestAccounts, which opens the extension's approval window), reads the network, the accounts, and the balance, and exercises message signing and a small self-send — each behind its own approval. Serve this folder with any static file server and open it in a browser where the extension is installed.
